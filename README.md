# ShopScope

- 项目是什么：面向个人 TikTok Shop 商家的轻量浏览器扩展，辅助选品、寻找 1688 货源和管理商品风险。
- 解决的需求：在 Temu 浏览商品时快速寻找相似 1688 货源；后续辅助检查 TikTok Shop 重复铺货风险。
- 核心功能：悬停 Temu 商品主图后发起 1688 官方以图搜货，并在原页面查看货源卡片。
- 第一阶段：Temu 以图找 1688 货源；TikTok Shop 商品采集与重复铺货分析暂不开发。
- 使用方式：`npm install` 后运行 `npm run build`，在 Chrome 扩展管理页加载 `dist/`；打开 Temu 列表页，悬停商品主图并点击搜图按钮。
- 使用限制：仅提交用户点击的商品图片给 1688 官方搜图；使用浏览器已有的 1688 会话，不保存密码或完整 Cookie，也不绕过安全验证。
- 迁移来源：1688 搜图业务层复用了用户提供的 `1688-image-search-migration-core-v0.16.2.zip`；Temu 入口依据用户提供的页面采样重新实现。
